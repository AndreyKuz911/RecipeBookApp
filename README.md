# RecipeBookApp

Проект «Книга рецептов» — это клиент-серверное мобильное приложение для публикации, поиска и обсуждения рецептов.

Приложение поддерживает полный пользовательский сценарий: от регистрации до взаимодействия с другими авторами. Пользователь может создать аккаунт, войти в систему, просматривать и редактировать свой профиль, загружать аватар, а также просматривать профили других пользователей.

Функционал работы с рецептами включает:

просмотр ленты новых рецептов; открытие подробной карточки рецепта; создание собственных рецептов с описанием, категорией, временем приготовления, шагами и изображениями; редактирование и удаление своих рецептов; поиск рецептов по ключевым словам; фильтрацию по категориям и другим параметрам.
Социальные возможности приложения:

переход в профиль автора из карточки рецепта; подписка и отписка на авторов; просмотр рецептов конкретного пользователя; добавление рецептов в избранное и удаление из избранного; оценка рецептов через лайк/дизлайк; добавление комментариев и просмотр обсуждений.
Также реализованы сценарии устойчивой работы: сохранение пользовательской сессии, обновление данных после повторного входа, корректная обработка ошибок сети и сервера, повторные попытки загрузки.

## Как указать BASE_URL сервера

По умолчанию в [app/build.gradle.kts](/C:/Users/andre/AndroidStudioProjects/RecipeBookApp/app/build.gradle.kts) используется:

```kotlin
buildConfigField("String", "BASE_URL", "\"http://10.0.2.2:8080/\"")
```

Для Android Emulator:

- `http://10.0.2.2:8080/`

Для реального телефона:

- `http://<IP_ВАШЕГО_ПК>:8080/`

После смены адреса пересоберите приложение.

## Запуск

1. Запустите backend `RecipeBookServer`.
2. Проверьте `BASE_URL`.
3. Откройте проект в Android Studio.
4. Запустите конфигурацию `app`.

Локальные тесты:

```bash
./gradlew testDebugUnitTest
```

Компиляция UI tests:

```bash
./gradlew compileDebugAndroidTestKotlin
```
